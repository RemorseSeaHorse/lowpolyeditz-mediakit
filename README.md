# lowpolyeditz media kit

Public media kit for POLY (@lowpolyeditz), served by GitHub Pages from this repo.

## Update the numbers

Everything that changes lives in **`data.js`**: views, followers, audience split, top reels, prices, the "updated" date. Edit it, commit, push. The page redraws itself; the link never changes.

- New reel thumbnail: drop a 348×548 JPG into `img/` and add a line to `reels` in `data.js`.
- New hero image: replace `img/hero.jpg` (3:4).
- Layout and styling: `index.html`.
